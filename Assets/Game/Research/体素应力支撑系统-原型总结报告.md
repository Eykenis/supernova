## 2. 算法实现状态

### 2.1 论文理论 → 原型实现的映射

| 论文概念 | 原型实现 | 状态 |
|----------|---------|------|
| EBC_LB 边介数中心性 | BFS 多源连通性检测 | ✅ 已实现 |
| 边界感知（仅加载边界→对面边界） | 锚点 = 基岩 (Y=0)，源 = 破坏点，目标 = 所有实心体素 | ✅ 已实现 |
| 长度加权最短路径 | 均匀网格 → 退化为无权 BFS | ⚪ 不需要 |
| 级联效应检测 | 迭代 BFS 级联 | ✅ 已实现 |
| 脆弱/濒危检测 | "下方无支撑" 悬挑启发式 | ✅ 已实现 |

### 2.2 核心 API

```csharp
// 增量分析 — 每次破坏后调用
SupportAnalysisResult result = graph.Analyze(
    removedVoxels,
    solidity: pos => IsSolid(pos),
    isAnchor: pos => pos.y <= 0 && IsSolid(pos));

// result.CollapsedVoxels   → 需要倒塌的体素
// result.FragileVoxels     → 支撑脆弱的体素（下方无实心体素）
// result.AffectedVoxels    → 受影响的所有体素
// result.CascadeIterationsUsed → 级联迭代次数

// 全局扫描 — 初始加载时调用
SupportAnalysisResult result = graph.FullScan(solidity, isAnchor, sizeX, sizeY, sizeZ);
```

## 7. 关键经验

1. **均匀网格是最简特例**：论文的 EBC_LB 在均匀体素网格中退化为多源 BFS 连通性检测——长度加权和 Dijkstra 都不需要
2. **级联才是难点**：一次破坏可能触发连锁反应，必须迭代检测，但需要上限防止无限循环
3. **Fragile 检测需要物理直觉**：BFS parent count ≠ 独立支撑路径数，在网格中用"下方无体素"启发式更简单也更有物理意义
4. **隔离设计有效**：整个原型放在独立 namespace 和文件夹下，零侵入现有代码
