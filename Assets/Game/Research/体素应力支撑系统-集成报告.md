## 2. 集成机制

### 架构

```
VoxelPlayerInteractor.terrain (MonoBehaviour field)
    │
    │  ResolveReferences() 通过 FindObjectsOfType<MonoBehaviour>()
    │  找到实现 IVoxelTerrain 的组件
    ▼
VoxelSupportInjector : MonoBehaviour, IVoxelTerrain
    │
    │  realTerrain = 真实的 MinecraftCaveInfiniteWorld
    │
    ├── IVoxelTerrain.TryMineVoxel()  → 先调用 realTerrain，再 RunSupportAnalysis()
    ├── IVoxelTerrain.TryMineBrush()  → 先调用 realTerrain，再 RunSupportAnalysis()
    ├── IVoxelTerrain.TrySetVoxelAndRebuild() → 先调用 realTerrain，再 RunSupportAnalysis()
    │
    └── RunSupportAnalysis()
        ├── VoxelSupportGraph.Analyze() → collapsedVoxels
        └── foreach collapsed → realTerrain.TrySetVoxelAndRebuild(Air)
```

### 关键设计决策

1. **Injector 本身是 MonoBehaviour + IVoxelTerrain**，而非纯 C# 代理。因为 `VoxelPlayerInteractor.ResolveReferences()` 每次都通过 `FindObjectsOfType<MonoBehaviour>()` 查找，纯 C# 代理会被覆盖。Injector 作为 MonoBehaviour 会被自然发现并保留。

2. **只在破坏时分析**：不扫描全图（O(N)），只在 `Destroyed=true` 时触发增量 BFS（O(k)，k=受影响子图）。

3. **倒塌体素通过 `realTerrain.TrySetVoxelAndRebuild()` 移除**：复用世界的优先网格队列，网格在当帧重建。

4. **MaxCollapsesPerFrame 保护**：单帧最大倒塌数上限，超出则下帧继续。

## 4. 使用方式

### 构建集成场景
打开 Unity Editor → 菜单 `Supernova/Support/Build Voxel Support Integration Scene`

### 测试
1. 打开 `Assets/Scenes/Prototypes/VoxelSupportIntegration.unity`
2. Enter Play Mode
3. 使用镐挖掘洞穴墙壁/地板
4. 观察 Console 中的 `[VoxelSupportInjector]` 日志
5. 当破坏内容失去支撑时，对应体素被自动设为 Air

## 5. 已知局限

| 局限 | 展望 |
|------|------|
| 无倒塌动画 | 仅沉默地移除体素，Phase 3 目标 |
| 无视觉反馈（粒子/裂纹） | Fragile 体素未被可视化 |
| 配置需在 Editor 中手动调整 | 可添加控制台命令 |
| 仅单帧内处理 | 大量倒塌可能跨帧 |
