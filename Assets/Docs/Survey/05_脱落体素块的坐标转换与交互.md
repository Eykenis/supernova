# 脱落体素块的坐标转换与交互

## 核心结论

独立脱落的体素块不会把内部体素重新编号。

每个体素一直保留脱落前的原始整数网格坐标：

```text
C = (x, y, z)
```

动态刚体额外保存一个 `Pivot`，将原始大坐标转换成以刚体质心为原点的局部坐标：

\[
\boxed{
P_{local}(C)=C\cdot S-Pivot
}
\]

其中：

- \(C\)：原始整数体素坐标；
- \(S\)：`voxelSize`；
- `Pivot`：脱落块在原地形局部空间中的质心；
- \(P_{local}\)：体素在动态刚体局部空间中的位置。

刚体移动、旋转后：

\[
\boxed{
P_{world}(C)=M_{body}(C\cdot S-Pivot)
}
\]

交互时把世界射线逆变换回刚体局部空间，再通过：

\[
\boxed{
C_{continuous}=\frac{P_{local}+Pivot}{S}
}
\]

恢复原体素网格坐标。

---

## 1. 四种坐标空间

### 原始体素网格坐标

\[
C=(C_x,C_y,C_z)
\]

它是整数坐标，作为体素身份保存在：

```csharp
Dictionary<Vector3Int, VoxelSample> samples
```

刚体掉落、旋转或分裂都不会改变该坐标。

### 地形局部空间

体素坐标乘体素尺寸：

\[
\boxed{
P_{terrain}=C\cdot S
}
\]

例如：

```text
C = (100, 20, 10)
S = 0.42
Pterrain = (42, 8.4, 4.2)
```

### 动态刚体局部空间

脱落块计算 Mesh 质心 `Pivot`，所有 Mesh 顶点和碰撞体顶点减去它：

\[
\boxed{
P_{local}=C\cdot S-Pivot
}
\]

这样刚体原点位于自身质心附近，有利于旋转、碰撞和浮点精度。

### 世界空间

完整公式：

\[
\boxed{
P_{world}
=
T_{body}
+
R_{body}
\left(
S_{body}\odot(C\cdot S-Pivot)
\right)
}
\]

若没有非均匀缩放：

\[
P_{world}=T_{body}+R_{body}(C\cdot S-Pivot)
\]

---

## 2. 脱落瞬间为什么不跳动

创建刚体时：

```csharp
root.position = terrainTransform.TransformPoint(pivot);
root.rotation = terrainTransform.rotation;
root.localScale = terrainTransform.lossyScale;
```

Mesh 顶点减去 `Pivot`，刚体整体又放到原地形的 `Pivot` 世界位置。

设地形变换为 \(M_{terrain}\)，则：

\[
T_{body}=M_{terrain}(Pivot)
\]

刚体中体素的世界位置：

\[
P_{world}
=
M_{terrain}(Pivot)
+
R_{terrain}S_{terrain}(C\cdot S-Pivot)
\]

展开后 `Pivot` 抵消：

\[
\boxed{
P_{world}=M_{terrain}(C\cdot S)
}
\]

这正是脱落前的位置，因此视觉上不会瞬移。

---

## 3. 世界射线转换到刚体局部空间

世界射线：

\[
R_{world}(t)=O_{world}+tD_{world}
\]

射线起点转换：

\[
\boxed{
O_{local}=M_{body}^{-1}O_{world}
}
\]

代码：

```csharp
localOrigin =
    transform.InverseTransformPoint(worldRay.origin);
```

项目还把世界射线终点一起转换：

\[
E_{world}=O_{world}+D_{world}L_{world}
\]

\[
\boxed{
E_{local}=M_{body}^{-1}E_{world}
}
\]

随后：

\[
V_{local}=E_{local}-O_{local}
\]

\[
L_{local}=\|V_{local}\|
\]

\[
\boxed{
D_{local}=\frac{V_{local}}{\|V_{local}\|}
}
\]

这种方式能正确处理刚体缩放。

---

## 4. 与真实可见表面精确相交

动态刚体的凸碰撞体只负责物理，不一定与可见 Marching Cubes 表面完全一致。

每个动态块因此保存 `VoxelMeshRaycastBvh`，其中顶点同样位于以 `Pivot` 为中心的局部空间：

```csharp
vertices[i] = sourceVertices[i] - pivot;
```

BVH 用包围盒快速排除无关三角形，再与候选三角形精确相交，并保存最近距离。

局部命中点：

\[
\boxed{
H_{local}=O_{local}+D_{local}d_{local}
}
\]

---

## 5. 从局部命中点恢复体素坐标

已知：

\[
P_{local}=C\cdot S-Pivot
\]

移项得到：

\[
\boxed{
C_{continuous}=\frac{P_{local}+Pivot}{S}
}
\]

命中点位于表面，为避免浮点误差，先向实体内部移动：

\[
\boxed{
H_{inside}
=
H_{local}
+
D_{local}(0.05S)
}
\]

再计算：

\[
\boxed{
G=\frac{H_{inside}+Pivot}{S}
}
\]

---

## 6. 检查 Marching Cubes 单元的八个角

连续网格位置向下取整：

\[
C_0=
(\lfloor G_x\rfloor,\lfloor G_y\rfloor,\lfloor G_z\rfloor)
\]

候选：

\[
C_i=C_0+O_i,\quad O_i\in\{0,1\}^3
\]

系统检查八个角中仍存在于 `samples` 字典里的实体体素。

每个候选的刚体局部位置：

\[
\boxed{
P_i=C_i\cdot S-Pivot
}
\]

---

## 7. 八个候选中如何选择

候选到表面命中点的距离：

\[
D_{surface}(C_i)=\|P_i-H_{local}\|^2
\]

优先选择该距离最小的体素。

若距离几乎相同，则使用射线深度：

\[
D_{ray}(C_i)
=(P_i-O_{local})\cdot D_{local}
\]

选择射线方向上更靠前的体素。

\[
\boxed{
C_{hit}
=
\arg\min_{C_i}
\left(
D_{surface}(C_i),
D_{ray}(C_i)
\right)
}
\]

---

## 8. 命中结果转换回世界空间

世界命中点：

\[
\boxed{
H_{world}=M_{body}H_{local}
}
\]

世界法线使用逆转置矩阵：

\[
\boxed{
N_{world}
=
Normalize((M_{body}^{-1})^TN_{local})
}
\]

世界命中距离：

\[
\boxed{
d_{world}=\|H_{world}-O_{world}\|
}
\]

---

## 9. 为什么旋转后仍能恢复同一体素

体素世界位置：

\[
P_{world}=M_{body}(C\cdot S-Pivot)
\]

逆变换：

\[
P_{local}=M_{body}^{-1}P_{world}
\]

恢复坐标：

\[
C'
=
\frac{P_{local}+Pivot}{S}
\]

代入：

\[
C'
=
\frac{
M_{body}^{-1}
M_{body}(C\cdot S-Pivot)
+Pivot
}{S}
\]

矩阵和逆矩阵抵消：

\[
\boxed{
C'=C
}
\]

所以无论刚体移动、旋转或翻滚多少次，都可以恢复同一个原始体素坐标。

---

## 10. LineageId 保证分裂后的稳定寻址

目标地址不是单独的刚体引用，而是：

\[
\boxed{
Address=(LineageId,Coordinate)
}
\]

`DynamicVoxelBodyRegistry` 维护：

```text
(LineageId, Coordinate) → 当前所属 DynamicVoxelBody
```

如果玩家挥镐后存在动画延迟，而目标刚体在伤害生效前发生分裂，系统仍能根据相同的体素坐标找到它现在所属的新刚体。

---

## 11. 刚体分裂时如何保持位置连续

原刚体旧质心：

\[
Pivot_{old}
\]

每个新连通块的新质心：

\[
Pivot_i
\]

新刚体原点在旧刚体局部空间中的偏移：

\[
\boxed{
P_{newOrigin,local}=Pivot_i-Pivot_{old}
}
\]

转换到世界空间：

\[
\boxed{
T_i=M_{old}(Pivot_i-Pivot_{old})
}
\]

新刚体内体素局部位置：

\[
P_{i,local}=C\cdot S-Pivot_i
\]

组合后：

\[
P_{i,world}
=
T_{old}
+
R_{old}S_{old}(Pivot_i-Pivot_{old})
+
R_{old}S_{old}(C\cdot S-Pivot_i)
\]

消去 \(Pivot_i\)：

\[
\boxed{
P_{i,world}
=
T_{old}
+
R_{old}S_{old}(C\cdot S-Pivot_{old})
}
\]

等于分裂前的位置，因此不会跳动。

每个新刚体还使用：

```csharp
sourceBody.GetPointVelocity(newPosition)
```

取得该质心位置分裂前的点速度：

\[
\boxed{
V_i=V_{linear}+\omega\times(T_i-T_{old})
}
\]

从而保持运动连续。

---

## 12. 爆炸坐标转换

动态体素参与爆炸时，系统将每个体素转换到当前世界位置：

\[
\boxed{
P_{world}(C)=M_{body}(C\cdot S-Pivot)
}
\]

再计算到爆心的距离：

\[
\boxed{
d(C)=\|P_{world}(C)-P_{explosion}\|
}
\]

因此动态块无论怎样旋转，爆炸判断都基于体素当前真实位置。

---

## 13. 完整交互流程

```text
地形失去支撑
    ↓
保存原始体素坐标C和VoxelSample
    ↓
生成Marching Cubes Mesh
    ↓
计算质心Pivot
    ↓
MeshLocal = MeshTerrain - Pivot
    ↓
刚体放到TerrainTransform(Pivot)
    ↓
刚体移动、旋转
    ↓
世界射线逆变换为刚体局部射线
    ↓
BVH命中真实局部三角形
    ↓
G = (Hinside + Pivot) / voxelSize
    ↓
检查所在单元的8个实体采样
    ↓
得到原始整数体素坐标C
    ↓
使用(LineageId, C)找到当前所属刚体
    ↓
执行挖掘并重新生成Mesh、碰撞体和Pivot
```

## 最核心的四条公式

\[
\boxed{
P_{local}=C\cdot S-Pivot
}
\]

\[
\boxed{
P_{world}=M_{body}(C\cdot S-Pivot)
}
\]

\[
\boxed{
P_{local}=M_{body}^{-1}P_{world}
}
\]

\[
\boxed{
C_{continuous}=\frac{P_{local}+Pivot}{S}
}
\]
